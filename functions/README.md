# Firebase Functions

This package contains the backend Cloud Functions for StoryInColor — Stripe checkout + webhook, AWS SES emails, image-generation, share-link minting, admin dashboard, and the Pixel/CAPI server-side conversion mirror.

## Email functions

Two callable functions backed by AWS SES (v3 SDK):

1. **`sendWelcomeEmailNotification`** — fires on first signup; sends a welcome email to the new user.
2. **`submitContactForm`** — fires when a visitor submits the contact form on `/contact`; sends the message to `info@storyincolor.com` and (if set) to `ADMIN_NOTIFICATION_EMAIL`.

## Setup

### AWS SES (one-time)

1. Verify your domain in SES (Console → Verified identities). Add the TXT + CNAME records to your DNS.
2. Verify DKIM (3 CNAMEs auto-generated by SES Easy DKIM).
3. Move the SES account out of sandbox if needed (Console → Request production access).
4. Create an IAM user with `ses:SendEmail` permissions; grab the access key + secret.

### Firebase secrets

Set the SES credentials in Secret Manager:

```bash
firebase functions:secrets:set AWS_ACCESS_KEY_ID
firebase functions:secrets:set AWS_SECRET_ACCESS_KEY
firebase functions:secrets:set SENDER_EMAIL_ADDRESS
```

`AWS_REGION` is NOT a secret — it lives in `functions/.env` (default `us-east-1`).

### Other secrets used by these functions

```bash
# Stripe
firebase functions:secrets:set STRIPE_SECRET_KEY
firebase functions:secrets:set STRIPE_WEBHOOK_SECRET

# OpenAI image generation
firebase functions:secrets:set OPENAI_API_KEY

# CAPI / GA4 server-side conversion mirror
firebase functions:secrets:set META_CAPI_TOKEN
firebase functions:secrets:set GA4_MP_API_SECRET
```

## Deploy

```bash
npm run build       # tsc to lib/
firebase deploy --only functions
```

The `firebase.json` `predeploy` hook runs the build automatically; you can also `firebase deploy --only functions:<functionName>` to redeploy a single function.

## Verifying email delivery

After a real signup or contact-form submission:

```bash
gcloud functions logs read sendWelcomeEmailNotification --gen2 --region us-central1 --project storyincolor-ai --limit 50
```

If SES accepted the message you'll see `MessageId: 0100...` and `[Email] ... successfully queued`. Whether Gmail/Outlook delivers to Inbox vs Promotions vs Spam is downstream of SES — see the project's audit notes for how to investigate inbox placement.
